# Rustmatics repository instructions

Keep user-created builds and generated outputs local. Save them under `artifacts/` and exclude them from Git checkpoints and commits. This includes RustEdit `.prefab` exports, `.rusterprefab` assemblies, `.ruster` projects, `.map` exports, terrain companion files, screenshots, and verification reports.

Stage application code, tests, and documentation explicitly. Leave changes to already-tracked files under `artifacts/` out of the index unless the user explicitly asks to commit those files.
